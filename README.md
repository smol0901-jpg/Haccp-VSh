# HACCP Control Enterprise v6.0

Профессиональная серверная программа для локальной сети с расширенным функционалом для управления документами пищевой безопасности (HACCP).

## 🚀 Возможности системы

### Функциональные возможности (100+ фич)

#### Управление шаблонами
- Создание, редактирование, удаление шаблонов документов
- Категоризация шаблонов (температура, влажность, гигиена, хранение, производство, доставка)
- Импорт/экспорт шаблонов в JSON
- Дублирование шаблонов
- Поиск и фильтрация шаблонов
- Статистика использования шаблонов
- Версионирование шаблонов
- Публичные/приватные шаблоны

#### Управление документами
- Создание документов из шаблонов
- Статусы документов (черновик, утвержден, архив)
- Утверждение документов с электронной подписью
- Срок действия документов
- Теги и категоризация
- Поиск по документам
- История изменений
- Дублирование документов

#### Пользователи и авторизация
- JWT аутентификация
- Ролевая модель (admin, user)
- Регистрация новых пользователей
- Профиль пользователя
- Смена пароля
- Журнал входов
- Активация/деактивация пользователей

#### Экспорт данных
- Экспорт в Excel (.xlsx)
- Экспорт в JSON
- Полный бэкап системы
- Экспорт журнала аудита в CSV
- Печать в PDF через браузер

#### База данных SQLite
- Хранение шаблонов
- Хранение документов
- Пользователи и роли
- Настройки системы
- Журнал аудита
- Категории шаблонов

#### WebSocket
- Real-time уведомления
- Синхронизация между клиентами
- Онлайн статус пользователей

## 🔧 Установка и запуск

### Сервер
```bash
cd /workspace/haccp-server
npm install
npm start
```

Сервер запустится на порту 3000.

### Клиент
Откройте в браузере: `http://localhost:3000`

## 📡 API Endpoints

### Авторизация
- POST `/api/auth/login` - Вход
- POST `/api/auth/register` - Регистрация
- GET `/api/auth/me` - Текущий пользователь

### Шаблоны
- GET `/api/templates` - Список шаблонов
- GET `/api/templates/:id` - Шаблон по ID
- POST `/api/templates` - Создать шаблон
- PUT `/api/templates/:id` - Обновить шаблон
- DELETE `/api/templates/:id` - Удалить шаблон
- POST `/api/templates/:id/duplicate` - Дублировать

### Документы
- GET `/api/documents` - Список документов
- POST `/api/documents` - Создать документ
- PUT `/api/documents/:id` - Обновить документ
- DELETE `/api/documents/:id` - Удалить документ
- POST `/api/documents/:id/approve` - Утвердить

### Экспорт
- GET `/api/export/document/:id/excel` - Excel документ
- GET `/api/export/templates/json` - JSON шаблоны
- GET `/api/export/backup/full` - Полный бэкап
