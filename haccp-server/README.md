# HACCP Control Server v6.0 - Enterprise Edition

## 📋 Описание системы

Профессиональная серверная программа для локальной сети управления документацией HACCP (Hazard Analysis and Critical Control Points). Система предназначена для предприятий пищевой промышленности, общественного питания и смежных отраслей.

### 🔧 Основные возможности

- **Многопользовательский режим** - работа в локальной сети с разграничением прав доступа
- **База данных шаблонов** - централизованное хранение и управление шаблонами документов
- **Визуальный конструктор** - создание и редактирование форм документов через веб-интерфейс
- **PWA (Progressive Web App)** - установка приложения на устройства, офлайн-режим работы
- **Экспорт документов** - PDF, Excel (.xlsx), Word (.doc), JSON
- **Импорт/Экспорт** - загрузка и выгрузка конфигураций в JSON
- **QR-кодирование** - автоматическая генерация QR-кодов для верификации документов
- **Автозаполнение** - умное заполнение данных с флуктуациями в пределах нормы

## 🚀 Быстрый старт

### Требования

- Node.js 18+ 
- npm 9+
- Современный браузер (Chrome, Firefox, Edge, Safari)

### Установка

```bash
cd /workspace/haccp-server/backend
npm install

cd ../frontend/public
# Файлы готовы к использованию

# Запуск сервера
cd ../backend
npm start
```

Сервер запустится на `http://localhost:3000`

### Доступ в сеть

Для доступа с других устройств в локальной сети:
- Узнайте IP-адрес сервера: `ip addr` (Linux) или `ipconfig` (Windows)
- Откройте в браузере: `http://<IP-адрес>:3000`
