# 🪟 HACCP Control Server v6.0 для Windows 10

## 📦 Что входит в комплект для твоего ПК

### Файлы для запуска:

| Файл | Назначение | Как использовать |
|------|------------|------------------|

## 🚀 Первый запуск

### Вариант 1: Через проводник (просто!)

1. Открой папку `haccp-server`
2. Дважды кликни на `start-haccp.bat`
3. Открой браузер: http://localhost:3000

### Вариант 2: Через PowerShell

```powershell
cd C:\project\haccp-control_v6\haccp-server
.\start-haccp.bat
```

### Вариант 3: Прямой запуск Node.js

```powershell
cd C:\project\haccp-control_v6\haccp-server
node src/server.js
```

## 🐛 Решение проблем

| Ошибка | Решение |
|--------|---------|
| **Port 3000 already in use** | `netstat -ano \| findstr :3000` → найди PID → `taskkill /PID <номер> /F` |
| **Cannot find module** | Запусти `npm install` |
| **Database locked** | Закрой все подключения к серверу, удали `haccp.db-shm` и `haccp.db-wal` |
| **Сервер не виден в сети** | Запусти `setup-firewall.bat` от имени администратора |
| **Node.js not found** | Установи Node.js с https://nodejs.org или перезапусти PowerShell |
| **JWT_SECRET error** | Смени значение в файле `.env` на уникальную строку |
