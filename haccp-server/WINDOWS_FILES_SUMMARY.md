## 🎯 КРАТКАЯ ИНСТРУКЦИЯ (3 шага)

### Шаг 1: Настройка (один раз)
```powershell
.\setup-windows-config.bat
```

### Шаг 2: Запуск сервера
```powershell
.\start-haccp.bat
```

### Шаг 3: Открыть в браузере
```
http://localhost:3000
```

**Логин:** `admin`  
**Пароль:** `admin123`

## 📊 Что делает каждый файл

### `start-haccp.bat`
- Проверяет наличие Node.js
- Устанавливает зависимости (если нет)
- Создает резервную копию БД
- Запускает сервер на порту 3000
- Показывает логи в консоли

### `setup-windows-config.bat`
- Проверяет Node.js
- Устанавливает npm пакеты
- Создает папки (uploads, exports, backups, logs)
- Проверяет базу данных

### `setup-firewall.bat`
- Создает правило брандмауэра для порта 3000
- Разрешает входящие подключения из сети
- Требует прав администратора

### `backup-db.ps1`
- Копирует haccp.db в папку backups/
- Сжимает в ZIP архив
- Удаляет старые копии (хранит 7 последних)
- Можно запускать по расписанию

## 🔄 Автозапуск при загрузке Windows

1. Открой **Планировщик заданий**
2. Создай задачу:
   - Имя: `HACCP Server`
   - Триггер: При входе в систему
   - Действие: `C:\Program Files\nodejs\node.exe`
   - Аргументы: `src/server.js`
   - Папка: `C:\project\haccp-control_v6\haccp-server`

## 📞 Поддержка

| Проблема | Решение |
|----------|---------|
| Сервер не запускается | Запусти `setup-windows-config.bat` |
| Port 3000 already in use | `taskkill /F /IM node.exe` |
| Не видно в сети | Запусти `setup-firewall.bat` от админа |
| Ошибка БД | Удали `haccp.db-shm` и `haccp.db-wal` |
