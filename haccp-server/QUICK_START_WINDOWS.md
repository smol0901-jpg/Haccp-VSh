## 🐛 Решение проблем

| Проблема | Решение |
|----------|---------|
| Port 3000 already in use | `netstat -ano \| findstr :3000` → `taskkill /PID <номер> /F` |
| Cannot find module | `npm install` |
| Database locked | Удали `haccp.db-shm` и `haccp.db-wal` |
| Сервер не виден в сети | Запусти `setup-firewall.bat` от админа |
| Ошибка JWT_SECRET | Смени в `.env` на уникальную строку |
